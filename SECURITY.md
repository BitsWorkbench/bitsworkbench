# Security

OpenCodeBot runs in the browser, keeps students' work there, and talks to boards
over USB. If you find a way for a page, a pack file or a program to reach
something it should not (another site, a student's files, a board it was not
given), please tell us privately before telling anyone else.

**Report it** through GitHub's private vulnerability reporting: the
**Security** tab of this repository, then **Report a vulnerability**. Or write
to support@firialabs.com with "Security" in the subject.

Say what you found, how to reproduce it, and which version and build (in
About). We will answer within a few working days, keep you told as we fix it,
and credit you in the changelog if you would like.

Only the latest release, and the site as served, are supported: fixes go into
`main` and the next release.
